# Contributing

## Reporting Issues

If you're using this skill with Claude and it fails to help you with a Manifold Markets task, please [open an issue](https://github.com/Thomas-Lemoine/manifold-markets-skill/issues) describing:

1. What you were trying to do
2. What went wrong (error messages, incorrect behavior, missing information, etc.)
3. Any relevant context (e.g., specific API endpoints involved)

This helps improve the skill for everyone.
